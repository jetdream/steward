# backend/src/chat/ — the agentic-chat surface (ARC-13 / CHT)

**Purpose.** The conversational SURFACE — the home's medium, not a separate
destination (UX-2, DEC-18 One-Home). It answers grounded in Memory + Strategy +
the content schedule, records redirects to the single Memory source, and leads
with non-blank openings. It HOSTS the interviewer skill (`../interviewer`) and
shares its DM-6/7 transcript store. Implements the behaviour spec **CHTS**
(`.spec/specs/cht-agentic-chat.yaml`).

| Fn (`index.ts`) | Role | Spec |
|---|---|---|
| `answer` | Grounded answer via the `chat-answer` Skill (assembles Memory + Strategy + schedule); records Q + A on the session | `@implements CHTS-1 v1` |
| `previewRedirect` / `applyRedirect` | Confirm-back BEFORE binding (deterministic gate, no write in preview), then write to Memory as a styleRule/taboo | `@implements CHTS-2 v1` |
| `suggestOpenings` | A few never-blank leading openings, EACH with a required reason | `@implements CHTS-4/CHTS-5 v1` |

**GR-2 on the answer surface (CHTS-1, the r1-challenger HIGH).** The chat answer
is the product's only user-facing LLM output that bypasses the PIPE-2 VAL chain,
so GR-2 (no legal/tax advice) is enforced HERE: the `chat-answer` Skill declines a
legal/tax question with a redirect, fail-safe (decline when it cannot confidently
clear the question) — the direct-to-founder analogue of GR-8's posture. Detection
is an LLM classifier (LRN-20), so it is the KEYED catch-rate tier (dormant on the
dev stub, which always answers) — proven by the keyed smoke, not the keyless eval.

**LRN-20 split.** DETERMINISTIC: grounding assembly, the confirm-back-before-bind
gate (CHTS-2), the required reason field on openings (CHTS-4), and single-Memory
writes. PROBABILISTIC: answer synthesis + the GR-2 decline (the `chat-answer`
Skill), held by the eval + smoke.

**Deferred.** CHTS-3 command actions (P1, reuse the GEN/PUB/AUT pipelines).
CHTS-5's guided Adjust (a content-engine redraft) + the disposition-triggered
enrichment loop land with APR (they need the draft dispositions APR owns).
Grounding uses the broad active set (`listGrounding`); query-relevant MEMS-4
retrieval is a refinement.

**Boundaries.** Org-scoped (ACC-3). Writes go only through Memory (MEMS-1); CHT-2
is one of MEMS-1's explicit correction channels. The transcript store is shared
with `../interviewer` (one DM-6/7 store, ARC-13).
