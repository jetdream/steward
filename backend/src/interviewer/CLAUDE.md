# backend/src/interviewer/ — the Interviewer skill (ARC-13 / INT)

**Purpose.** A curious thinking partner that fills Memory gaps — a SKILL, not a
surface. It runs in the shared conversation and reads/writes ONLY through Memory
(MEMS) + the single gap model (ONBS-3); no side channel. Implements the behaviour
spec **INTS** (`.spec/specs/int-interviewer.yaml`).

| File | Role | Spec |
|---|---|---|
| `store.ts` | DM-6/DM-7 transcript persistence: `startSession`, `appendMessage`, `getTranscript` (resumable, chronological) | `@implements INTS-2 v1` |
| `index.ts` | `createInterviewer` facade — `nextQuestions` (the `interview-questions` Skill, gap-gated + capped), `recordAnswer` (→ Memory MEMS-1), `openQuestions` (filtered gap view), `transcript` | `@implements INTS-1/2/4 v1` |

**LRN-20 split.** The DETERMINISTIC parts are question GATING (the ONBS-3 gap
model supplies the OPEN gaps — a resolved gap is `present` and never re-asked,
MEMS-6), the per-turn rate cap (`PER_TURN_CAP`), and resumable session state
(DM-6/7). The PROBABILISTIC part is conversational QUALITY — the
`interview-questions` Skill authors open, story-seeking questions — held by the
eval, not a deterministic guarantee.

**One source, no side channel.** Answers are written to Memory via the MEMS-1
free-remark path (`trigger: interview`, `correctionChannel: false` — ambiguous
input follows MEMS-5's narrower default, never a manufactured rule). The
open-questions list (INTS-4) is a FILTERED VIEW of the gap model, not a separate
list.

**Deferred.** INTS-3 periodic calendar-tied curiosity draws on the shared PRO-4
proactive-interruption budget (DEC-24) — it lands with the Proactive manager.
The agentic-chat surface (CHT) is a sibling in ARC-13 (a later increment); INT is
the questioning skill, CHT the conversational surface, sharing the enrichment loop
(CHT-5).

**Boundaries.** Org-scoped everywhere (ACC-3). The gap model is imported from
`../onboarding` (ONBS-3, the single source); Memory is the single knowledge store
(DEC-22).
