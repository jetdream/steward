# backend/src/media/ — the media library + picture gate (ARC-15 / GEN-3/4)

**Purpose.** Owns the DM-4 MediaAsset library and the GENS-3/4 picture gate.
Implements part of the behaviour spec **GENS** (`.spec/specs/gen-content-generation.yaml`).

| File | Role | Spec |
|---|---|---|
| `gate.ts` | The DETERMINISTIC gate: `editorialStateForDraft` (pictureless → awaiting_picture) + `canApprove` (no advance to approved without a picture) | `@implements GENS-3/GENS-4` |
| `index.ts` | `createMedia` facade — `upload` (blob store + DM-4 row), `attach` (clears awaiting_picture → draft, org-confined), `library` | `@implements GENS-3/GENS-4` |

**The hard invariant (GEN-3, GENS-4).** Every post carries a picture: a
freshly-generated master lands `awaiting_picture` (`persistDraft` uses
`editorialStateForDraft(false)`), a complete-but-blocked state — never an error.
`attach` links a MediaAsset and clears the gate to `draft`; `canApprove` (called by
APR's approve path) refuses approval without a picture. DETERMINISTIC, not an LLM
hope (LRN-20). AI imagery is disabled (GR-4) — assets are real uploads / ONBS-2
harvests only.

**Blob storage (ADR-0003).** Bytes go through the `../ports/blob.ts` port; the
dev/test adapter is a process-singleton in-memory store (`../adapters/blob/`). The
S3-compatible MinIO/R2 adapter (ADR-0007) lands with the deploy wiring (needs the
AWS SDK) — the port is stable, so it drops in without touching callers.

**Deferred.** The PRO-1 photo-request nudge on an awaiting_picture draft (with the
Proactive manager); library suggestion RANKING from Memory tags (an
embedding/LLM follow-on — the tags column is ready). Attach-from-library in the
Ready surface is APR (I15).

**Boundaries.** Org-scoped both sides of attach (ACC-3). The gate is imported by
`../content/store.ts` (persist) + the future APR approve path (`canApprove`).
