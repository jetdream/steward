# backend/src/publishing/ — Publisher + Channel Adapters (ARC-18 / PUB)

**Purpose.** The delivery layer: the **PUBS-2 per-channel technical profiles**
(config the content engine reads) AND the **Publisher** — scheduled, gated,
official-API delivery of approved ChannelVariants (PUBS-1) plus the append-only
publish log (PUBS-3). Implements the behaviour spec **PUBS**
(`.spec/specs/pub-publishing.yaml`).

| File | Role | Spec |
|---|---|---|
| `channel-profiles.ts` | `channelProfile(platform)` / `allChannelProfiles()` — the SINGLE source of each channel's char limit, media requirement, link handling, and rate ceiling | `@implements PUBS-2 v1` |
| `publish.ts` | `createPublisher` facade + the pure `publishability` gate; `schedule` / `publishVariant` / `publishLog` | `@implements PUBS-1/PUBS-3` |
| `../ports/publishing.ts` | the official-API publish port (ADR-0003, GR-6) | — |
| `../adapters/publishing/` | the dev/synthetic publisher (Meta IG-1 / X IG-2 deferred) | — |

**Config, not code (R-6).** Editing a limit updates adaptation + fit with no code
change; profiles are per-channel and ISOLATED. Launch channels: facebook_page /
instagram / threads / x (PUB-4 LinkedIn is P2).

**The publish gate (PUBS-1, load-bearing, deterministic).** `publishability` is
pure and is the ONE place "may this post now?" is decided: a variant posts only
when it is `scheduled`, NOT paused (AUT-3, `@backend/autonomy`), its
ChannelConnection is HEALTHY (ONBS-4, `@backend/channels`), and the subscription
is publishing-eligible (BILS-2). A blocked variant does NOT post and does NOT
error — it stays scheduled / surfaces the needs-you card (VAL-3), never a silent
failure. On the healthy path the credential opens server-side (SEC-10) and the
post goes out through the official-API port (GR-6).

**The publish log (PUBS-3).** A VIEW over `published` ChannelVariants (DM-5) —
destination (platform), timestamp (publishedAt), live link (publishedUrl), and the
EXACT text sent (the variant body at publish time). Append-only by construction (a
published variant is terminal); an auto-published post logs exactly like an
approved one.

**Deferred (documented, not silently dropped).**
- **Subscription eligibility** is STUBBED `true` (`subscriptionEligible`) until
  Billing (DM-11/BIL) lands — a cancelled/lapsed org must then stop publishing
  (BILS-2). `TODO(BIL)` in `publish.ts`.
- **Retry/backoff + operator failure queue** (OPS-1): a `post` failure currently
  propagates to the caller; the durable retry+alert queue lands with OPS.
- **Engagement-optimal slotting**: `schedule` takes an explicit `when`; the
  per-channel optimal-time model is a refinement.
- **Live Meta/X adapters** (GR-6 official APIs) + the **news cache-purge** path
  (NWS/IG-11) + the **AUT-1 TL1 veto window** (P2).
