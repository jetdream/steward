# features/onboarding/ — day one (XO-1 → XO-2 / XO-3)

**Purpose.** The day-one SHAPE of the home: arrival, watching Steward learn, the
correctable "here's what I know" review, and the first conversation. Realizes
`ONBS-2/3/5/6` and `INTS-1/2` against screen `XH-12`.

| File | Role |
|---|---|
| `dayOne.ts` | the deterministic decisions — day-one shape, the site proposal, findings rendering. Unit-tested (`dayOne.test.ts`) |
| `DayOne.tsx` | `useDayOne` — the region contents the shell renders |

**Not a screen, not a route.** `useDayOne` returns region *contents*, not a
component wrapping them: `Home` owns the region landmarks and their per-region
`inert` (DSS-24), so a wrapper between a region and its content would break that
contract. The shape switch lives in `HomeScreen` and is ONBS-6's deterministic
predicate — the home stops being day-one exactly when Steward knows enough to
write.

## Gotchas

- **Ingestion is proposed, not already running.** The mockup shows Steward
  mid-read at minute 0, but it can only read a source it knows, and the doorstep
  collects name + email only. The address's domain becomes a one-tap proposal
  with a decline; a silent read of a guessed domain is how Steward would file
  someone else's website as your mission. `proposedSiteFromEmail` returns null
  for public mail hosts for the same reason.
- **No 501(c)(3) verification line**, though XO-2 names one — the same recorded
  deferral as the doorstep's EIN field.
- **Where the mockup and XH-12 disagree, the region contract wins.** The mockup
  predates region formalization and draws one undivided phone stream; the
  ordering here is `ready` → `conversation` → `terminus`. Treatment still comes
  from the mockup.
- The correction box is reached by its `data-correction` hook, never by `id` —
  DSS-6 controls generate their own `id` to pair label and `aria-describedby`,
  and overriding it silently breaks that pairing.
- **Never open an interview session directly.** `useInterviewer` resumes first
  and exposes `ask()` as the only entry point; a caller that starts its own
  session strands the transcript it meant to continue (INTS-2).
