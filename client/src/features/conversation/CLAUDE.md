# features/conversation/ — region 3 of XH-12 (UXS-2)

**Purpose.** The home's conversation, and the **only** conversation surface in
the product. Realizes `UXS-2` and `CHTS-1/2/4/5` — grounded answers, the
confirm-back redirect gate, the never-blank composer.

| File | Role |
|---|---|
| `conversation.ts` | the deterministic rules: never-blank openings, the reason gate, `canSend`. Unit-tested |
| `Conversation.tsx` | the region — transcript, openings, composer, redirect confirm-back |

**There is no chat page.** `DEC-18` fused the chat page and the docked companion
into this region, so interviewer questions, chat answers and redirects all appear
here inline. Chat and the interviewer persist through the **same session store**,
which is what makes it one conversation rather than two threads sharing a scroll.

## Gotchas

- **The composer's verb is declared, never inferred.** Ask / answer / lay down a
  rule are three different writes — nothing, a fact (`INTS-2`), a permanent
  styleRule (`CHTS-2`). Telling them apart is a semantic judgment and being wrong
  in the *binding* direction gives the org a rule nobody asked for, so the
  founder picks (LRN-20: no classifier where an affordance will do).
- **The redirect's two calls are the gate, not ceremony.** `previewRedirect`
  writes nothing; only `applyRedirect` binds. Never collapse them for
  convenience — a single-step version looks identical until it mis-reads an
  instruction and enforces it on every future draft.
- **`data-*` on a DSS component is silently dropped.** DSS components take only
  their declared props, so a hook passed to one is accepted by JSX and never
  reaches the DOM — a selector that can never match. Put it on a wrapper (see
  the `ReasonLine` uses here) or on a component that spreads `...rest`.
- The GR-2 decline and the honest unknown ride the LIVE answer; the persisted
  transcript keeps the answer text, which already carries the decline wording.
