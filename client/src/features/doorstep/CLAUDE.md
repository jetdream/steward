# features/doorstep/ — screen XO-6

**Purpose.** The only surface a signed-out founder sees: sign-up and sign-in.
Realizes `ONBS-1` (zero-homework signup) and the founder-facing half of
`ACCS-1` (sign-in yields the User; signup creates the User + Org + owner
Membership triple).

**Place in the experience spine.** Screen `XO-6`, parent flow `XO-2` ("arrival &
watch it learn"), journey `XO-1` (day one). Its exit is `XH-12` in day-one shape
— there is no step between them, which is what "no profile wizard, no checklist"
means in code: one form, one submit.

| File | Role |
|---|---|
| `Doorstep.tsx` | the screen. Pure presentation + local form state; the caller (`App.tsx`) owns the mutation |

**The screen has no mockup.** Every other in-scope screen has a founder-reviewed
HTML artifact under `design/mockups/`; this one does not. It is therefore
designed from the `XO-6` body plus the DSS inventory — `TextField` (DSS-6),
`Button` (DSS-5), the `typeRole` scale (DSS-3) — and introduces no visual value
of its own (GR-7). If a mockup is later reviewed, it wins.

## Gotchas

- **The EIN field is deliberately absent**, though `XO-6` names it. 501(c)(3)
  verification is a recorded deferral (see `backend/src/onboarding/CLAUDE.md`);
  `DM-1` has no EIN column and no registry lookup exists. Rendering the input
  would mean discarding what the founder typed, and rendering a "verification
  pending" state would promise a check that never runs — both are the fake
  states VAL-6 forbids. The screen says so in one line instead. **The field
  arrives with the lookup, not before.**
- **New-vs-returning is founder-declared, never inferred.** Probing whether an
  address is already registered would turn the doorstep into an account-existence
  oracle for anyone with a guess.
- The org name is optional on the wire even in "new" mode: `signupOrgName`
  (`@backend/accounts`) falls back to the email's local part, because ONBS-1 says
  nothing blocks on a missing field. An existing membership always wins — signing
  in never renames the org you already have.
