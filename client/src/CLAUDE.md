# client/src/ — the `@client` source root

The founder-facing SPA. Three layers, and the boundaries between them are the
constitution's, not a preference:

| Path | Role |
|---|---|
| `ds/` | the DSS component inventory — the ONLY source of visual values (GR-7) |
| `features/<area>/` | feature areas mirroring the experience spine (`doorstep/` = XO-6, `shell/` = XH-12) |
| `api/use<Domain>.ts` | the ONLY path to the backend — no component touches `useTRPC` or `fetch` |
| `App.tsx` | the single session branch: signed out → doorstep, signed in → home |
| `trpc.ts`, `main.tsx`, `index.css` | the tRPC client, the React root, and the theme import (DSS-1) |

A feature composes `ds/` and calls `api/`; it never reaches past either. Adding a
colour to a feature or a `fetch` to a component are the two ways this collapses.
