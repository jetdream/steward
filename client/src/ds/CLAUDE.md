# client/src/ds/ — the design system, realized (DSS-1..25)

**Purpose.** The founder-surface component inventory that `GR-7 v3` binds every
screen to. One file per DSS contract, each carrying `@implements DSS-n`. The
visual source of truth for each contract is its card in
`design/design-system/steward/preview/` — port from the card, don't invent.

**No ShadCN, no Radix here** (`DEC-42` / `ADR-0011`). Founder surfaces take no
new UI dependency: behaviour comes from native platform primitives, appearance
from these files. The scope is by *surface*, not package — the internal
ops/admin console keeps its `DEC-35` shadcn allowance elsewhere in `@client`.

| File | Contract | Role |
|---|---|---|
| `../index.css` | `DSS-1` | imports the steward theme — the single token source; no parallel scale, no fork |
| `accent.ts` | `DSS-2` | the one-accent-per-viewport guard: `accentFocal` marks the primary action, `countAccentFocals` is what dev AND e2e count |
| `type.ts` | `DSS-3` | type ROLES (display / subsection / cardTitle / body / secondary / meta / rhythm), never raw sizes |
| `a11y.ts` | `DSS-4` | the DS-4 baseline: `focusRing` (2px ink), `tapTarget` (≥44px), `srOnly`, `politeLiveRegion`, `regionLandmark`, `inertWhen` |

Components (`DSS-5..25`) land in E2/E3.

## Rules that bite

- **Tokens only.** A raw hex, px, or ms literal is a `DSS-1` violation. Resolve
  through the generated utilities (`bg-surface`, `text-muted`, `rounded-md`,
  `shadow-raised`, `duration-fast`). Arbitrary values are acceptable **only** as
  `[var(--token)]`, never as a literal.
- **`desktop:` is the only breakpoint variant.** Two layout modes, phone and
  desktop (DEC-19/DEC-20). Tailwind's `sm/md/lg/xl/2xl` still exist in the theme
  because the internal console's shadcn source needs them — using one here is a
  review defect (`.spec/conventions.yaml`, client scope; `LRN-29`).
- **The accent is not a colour you pick.** It marks THE primary action, the
  active-nav indicator, or one focal element — nothing else. Spread
  `accentFocal` on that element so the guard can count it.
- **Never the accent for focus.** The focus ring is 2px ink: org photography is
  the hero surface and terracotta vanishes against warm imagery (#Bind S4).

## Gotchas

- **A top-layer surface silently voids per-region `inert`** (`LRN-29`). Both
  Radix's `hideOthers()` and native `<dialog>.showModal()` inert the whole
  document outside the pane, making `inert = false` on the pinned zone a
  **no-op** — verified twice in headless Chromium during the ADR-0011 rounds.
  The summoned pane (`DSS-24`) MUST be non-modal (`.show()`), with `Escape`,
  scroll lock, the focus trap and dismissal hand-written. `inertWhen` exists to
  make the per-region choice explicit at each call site.
- **Client unit tests are DOM-free.** The root runner globs
  `client/src/**/*.test.ts` (not `.test.tsx`) and there is no jsdom environment.
  Test pure logic here; assert rendered state in the e2e suite instead.
- Editing the theme means editing `design/design-system/steward/tokens.css` and
  re-running `node design/design-system/steward/build-previews.mjs` — never
  hand-editing a `preview/*.html`.
